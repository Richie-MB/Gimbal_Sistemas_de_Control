# Gimbal - Sistemas de Control

Proyecto de Gimbal para Sistemas de Control

## Estructura del Repositorio

### 📝 `/codigos/`
Contiene los 3 códigos diferentes utilizados en el proyecto.

### 📚 `/libreria_arduino/`
Librerías de Arduino IDE necesarias para el funcionamiento del proyecto.

### 🖨️ `/archivos_stl/`
Archivos STL para impresión 3D de las piezas del gimbal.

### 📸 `/fotos_videos/`
Fotos y videos del proyecto en funcionamiento.
